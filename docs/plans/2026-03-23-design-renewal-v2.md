# サイトデザイン大幅リニューアル v2

## 概要

bellsanct.github.io をダークパープルベースのサイドナビ型レイアウトに全面刷新。
Brittany Chiang (brittanychiang.com) のレイアウト構成と、Lusion (lusion.co) のプレミアム感を参考にする。

## デザイン方針

- **ダークパープルベース固定** (`#2D2640` 系を発展) - テーマ切り替えなし
- **左サイドバー固定 + 右メインスクロール** のレイアウト
- アクセントカラー: 既存のラベンダー/ローズ/ゴールド/コーラルを活用
- フォント: Crimson Pro + Inter 維持

### モバイル (768px以下)
- サイドバーは上部に折りたたみ、ハンバーガーメニューで展開
- グリッドは2カラム → 1カラムに段階的に縮小

## セクション詳細

### サイドバー (固定)
- 名前: Bell_staymen04 (Crimson Pro, 大きめ)
- 肩書き: DJ / Organizer
- ナビ: Brittany Chiang風ラインインジケーター (スクロール位置連動)
- SNSアイコン: Twitter, GitHub, OuterMusicRoom (サイドバー下部)

### Profile (カード型) - 新規
- アバター画像を大きく表示
- バイオテキスト
- SNSリンクをアイコンで並べる
- 現状のターミナル風UIは廃止

### Events (グリッド) - 刷新
- 3-4カラムのグリッドレイアウト
- フライヤー画像をそのまま並べる
- ホバー: 半透明オーバーレイ + イベント名表示
- ダーク背景にカラフルなフライヤーが映える
- 既存の45枚のフライヤーデータはそのまま活用

### Works (カード型) - 維持
- 前回作成したWorks.vueをダークテーマ対応に調整

### Tools - 維持
- ダークテーマ対応に調整

### Contact - 維持
- ダークテーマ対応に調整

## 廃止する要素
- Hero セクション (サイドバーに名前・肩書きを常時表示するため不要)
- ダークモード切り替え機能
- ローディング画面 (シンプルに即表示)
- Hero装飾アニメーション (star, sparkle, shape)
- Footer (コピーライト1行のみ残す)
- ターミナル風Profile UI
